DuckMail API 文档

Base URL: https://your-api.example.com，本文档为脱敏示例，可直接替换为你的部署地址使用。

返回 API 密钥界面

鉴权方式

  • x-admin-key：仅用于 /admin/* 管理接口。
  • Authorization: Bearer dk_xxx：API Key，用于自动化开箱与域名读取。
  • Authorization: Bearer <jwt>：邮箱用户 Token，用于收信、提码、删信等。

核心流程

推荐流程：创建 API Key -> 开邮箱 -> 获取消息 -> 提取验证码。

# 1) API Key 查看可用域名
curl https://your-api.example.com/domains \
  -H "Authorization: Bearer dk_xxx"

# 2) 随机开邮箱（免密码）
curl -X POST https://your-api.example.com/mailboxes/open \
  -H "Authorization: Bearer dk_xxx" \
  -H "Content-Type: application/json" \
  -d '{"domain":"example-mail.test"}'

# 返回: {"address":"random-user@example-mail.test","token":"jwt",...}

# 3) 拉消息
curl https://your-api.example.com/messages?page=1 \
  -H "Authorization: Bearer USER_JWT"

# 4) 拉最新验证码
curl https://your-api.example.com/codes/latest \
  -H "Authorization: Bearer USER_JWT"

常用接口

  • GET /domains：获取已验证域名。
  • POST /accounts：创建邮箱账号（可密码模式）。
  • POST /mailboxes/open：免密码打开邮箱（手填或随机）。
  • POST /token：获取邮箱 Token（支持密码模式与免密码模式）。
  • GET /me：当前邮箱信息。
  • GET /messages：消息列表。
  • GET /messages/:id：消息详情（正文已做 MIME 解码）。
  • GET /messages/:id/code：从指定消息提取验证码。
  • GET /codes/latest：提取最新验证码。
  • PATCH /messages/:id：标记已读。
  • DELETE /messages/:id：删除消息。
  • DELETE /accounts/:id：删除当前邮箱。

管理接口（Admin）

  • POST /admin/login
  • GET /admin/stats
  • GET/POST/DELETE /admin/domains、POST /admin/domains/:id/verify
  • GET/POST/DELETE /admin/api-keys
  • GET /admin/accounts

错误码

  • 400 参数错误
  • 401 未授权/鉴权失败
  • 403 权限不足
  • 404 资源不存在
  • 409 资源冲突
  • 422 业务校验失败
  • 500 服务异常
